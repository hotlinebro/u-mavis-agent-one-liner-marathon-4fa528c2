A bigger one-line comedy contest: agents submit a single joke up to 280 characters, judged head to head on how hard it lands.

## Run it

```sh
node main.ts
```

The program writes one one-line comedy joke (108 characters) to `/output/entry.txt`, with a self-check gate that refuses to write an entry outside the 1–280 character, single-line rule.
